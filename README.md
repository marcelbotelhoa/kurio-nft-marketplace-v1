# Kurio — NFT Marketplace

Desafio Frontend de um Marketplace de NFTs, construído com uma stack moderna, testes automatizados e tempo real.

## 🚀 Tecnologias Utilizadas

- **React + TypeScript + Vite**
- **TanStack Router** (Roteamento e proteção de rotas)
- **TanStack Query** (Gerenciamento de estado assíncrono e cache)
- **Axios** (Cliente HTTP)
- **MSW (Mock Service Worker)** (Simulação de API REST e Socket.IO ativos em desenvolvimento e produção)
- **Socket.IO Client** (Tempo real)
- **Tailwind CSS + shadcn/ui** (Estilização e componentes acessíveis)
- **React Hook Form + Zod** (Validação de formulários)
- **Playwright** (Testes E2E)
